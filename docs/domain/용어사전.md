# 용어사전

Etude 도메인에서 쓰는 용어를 한국어/영어/설명으로 정리한다. 코드의 클래스명·필드명은 여기 영어
표기를 그대로 따른다 — 이 표가 기준이고, 코드가 여기와 다르면 코드를 고치거나 이 표를 갱신한다.

**적용 범위**: 지금은 `quest`(퀘스트/퀘스트셋) 도메인만 다룬다. 다른 도메인(`auth`, `user`)은 아직
용어 정리를 안 했다 — 필요해지면 그때 추가한다 (근거:
[reference_projects_action_items.md 2-2](../research/reference_projects_action_items.md)).

| 한국어 | 영어 | 설명 |
|---|---|---|
| 퀘스트셋 | QuestSet | 실습 주제 하나를 묶는 단위. 여러 퀘스트를 순서대로 담는다. 공개(`isPublic`) 여부에 따라 모든 사용자에게 보이거나, 개별 접근 권한을 받은 사용자에게만 보인다. |
| 퀘스트 | Quest | 퀘스트셋에 속한 개별 실습 문제 하나. 제목, 설명, 힌트, 정답(solution), 채점 명령(gradeCmd)을 갖는다. `orderIndex`로 퀘스트셋 안에서의 순서가 정해진다. |
| 퀘스트셋 접근 권한 | QuestSetAccess | 특정 사용자가 특정 비공개 퀘스트셋에 접근할 수 있다는 사실을 나타내는 레코드. `questSetId`와 `userId` 조합으로 존재 여부만 표현한다 — 그 자체로는 행동이 없다. |
| 공개 여부 | isPublic | 퀘스트셋이 모든 로그인 사용자에게 공개되는지(`true`), 개별 권한을 받은 사용자에게만 공개되는지(`false`)를 나타내는 `QuestSet`의 상태. `changePublic()`으로만 바뀐다. |
| 접근 가능 여부 | canAccess | "이 사용자가 이 퀘스트셋을 볼 수 있는가"를 판단하는 규칙 자체를 가리키는 말. 공개 세트이거나, 관리자이거나, `QuestSetAccess`가 있으면 접근 가능하다 (`QuestService.canAccess`). |
| 채점 명령 | gradeCmd | 퀘스트를 통과했는지 자동으로 확인하기 위해 샌드박스에서 실행하는 명령. JSON으로 저장된다. |
| 설정 명령 | setupCmd | 퀘스트용 샌드박스 컨테이너를 만들 때 초기 상태를 준비하기 위해 실행하는 명령. JSON으로 저장되며 선택값이다. |
| 순서 | orderIndex | 퀘스트셋 안에서 퀘스트가 노출되는 순서. 값이 작을수록 먼저 나온다. |
