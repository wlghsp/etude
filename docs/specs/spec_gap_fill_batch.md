# 명세 — 보강 문제 모음 (명령어 빈틈 채우기)

> 상태: **구현 완료(로컬), 화면 확인 대기** (2026-10-30)

## 배경

자주 쓰는 리눅스 명령어 목록을 현재 문제와 대조해, 풀이에 한 번도 나오지 않는 것을 확인했다 (`less`, `userdel`, `killall`, `htop`, `gunzip`, `traceroute`).

## 판단과 처리

| 명령어 | 처리 |
|---|---|
| `gzip` / `gunzip` | 세트 7 에 문제 2개 추가 (#10 파일 하나 압축, #11 `.gz` 풀기) |
| `userdel` | 세트 21 에 #16 추가 (`-r` 로 홈 디렉터리까지 삭제) |
| `killall` | 샌드박스 이미지에 없다. 같은 역할의 `pkill` 을 세트 3 #11 (`ps` 징검다리)에서 다룬다 |
| `less` | **제외.** 샌드박스에 설치돼 있지 않아 직접 해 볼 수 없고 중요도도 낮다. 객관식만 만들면 외우기가 된다 |
| `htop` | 이미지에 없고 `top`(세트 27 #5)으로 충분하다 |
| `traceroute`, `ping` | 이미지에 없다. 추가하려면 `Dockerfile.linux` 변경이 필요해 보류 (세트 36 은 `getent`·`nc`·`curl` 로 구성) |
| `sudo` | 학습자가 root 라서 의미가 없다. 일반 사용자 시나리오가 필요해 보류 |
| `cd`, `cp`, `mv`, `rm`, `tail` | 문제 수는 적지만 기본이라 반복문(세트 35)·이름으로 통신하기(세트 36)에서 자연스럽게 반복된다 |

## 검증

- `미검증`: 화면 흐름.
