# 명세 — 화면 개선 묶음 (탭, 로딩, 진행 표시, 성취감)

> 상태: **구현 완료(로컬), 화면 확인 대기** (2026-10-30). 참고: KodeKloud(탭·로딩·모듈 진행), 듀오링고(축하 연출).

## 배경

화면이 검정·회색뿐이라 밋밋하고, 문제 설명·힌트·풀이가 위아래로 쌓여 내용이 길어지면 읽기 어렵다는 피드백. 세트 완료의 성취감이 약하다.

## 변경

- **탭 구조** (문제 화면): `문제 / 힌트 / 풀이(실습형만)`. 한 번에 하나만 보여 각 내용이 길어져도 깔끔하다.
  - 힌트는 탭을 여는 순간 사용으로 기록(힌트가 없는 문제는 기록하지 않는다), 풀이는 **문제마다 처음 열 때 한 번 확인 모달**을 거쳐 기록한다. 이후 탭 전환은 다시 묻지 않는다.
  - 사용한 힌트·풀이 탭에는 색 점이 남는다.
- **칸 진행 막대**: 문제 수만큼 칸을 나눠 푼 문제는 초록, 지금 문제는 파랑으로 보인다 (세트 안 진행 표시일 뿐 기록 단위는 여전히 세트 완료).
- **로딩 화면**: 돌아가는 링과 함께 **학습 팁**(Tab 자동완성, `Ctrl+C`, `--help`, `>`와 `>>` 등 12개)이 5초마다 바뀐다. 터미널 연결과 환경 준비 두 곳에 같은 화면을 쓴다.
- **터미널 시작 로고**: 터미널이 열릴 때 작은 "Etude" ASCII 로고를 글자마다 다른 색으로 찍는다 (KodeKloud 환영 문구 참고).
- **홈 상단 패널**: 인사, 큰 전체 진행 링, 🔥 **연속 학습일**(세트 완료 기록에서 계산, 오늘 아직 안 했어도 어제까지 이어졌으면 유지), 완료 세트 수, 최근 7일 완료 횟수, 그리고 **이어서 학습하기** 버튼(가장 최근에 끝낸 분야에서 아직 안 끝낸 첫 세트, 없으면 다른 분야). 이어서 학습할 분야는 처음부터 펼쳐 둔다.
- **분야 카드**: 분야마다 색 그라데이션 카드에 아이콘, "다음: #번호 제목", 진행 링.
- **홈**: 분야마다 포인트 색(리눅스 주황, 도커 하늘, k8s 보라)과 분야·단원 진행 링을 보이고, 단원을 모두 끝내면 초록 체크와 "단원 완료" 표시가 붙는다.
- **성취감 연출**:
  - 세트 완료 화면: 화면 전체 색종이, 통통 튀는 트로피와 반짝이, 무지개 글자 "세트 완료!".
  - 업적 배지: **퍼펙트**(힌트·풀이 없이 모두), **전부 한 번에 성공**.
  - **단원 완료 배너**: 이 세트를 처음 끝냈고 단원의 모든 세트가 완료되면 배너와 더 큰 색종이.
  - 문제 하나를 맞히면 기존 색종이에 더해 효과음.
- **효과음**: 기본은 꺼짐. 위 막대의 스피커 버튼으로 켜고 끄며(브라우저에 저장), 켜면 정답·오답·완료에 짧은 소리가 난다. 시스템 설정의 "동작 줄이기"를 켠 사용자에게는 움직이는 효과를 끈다.
- **로그인**: 선택할 수 있는 **아이디 저장**(기본 켬, 이 브라우저에만 저장, 비밀번호는 저장하지 않음), 비밀번호 보기 토글, 아이디가 있으면 비밀번호 칸에 자동 포커스, 브라우저 자동완성 속성.
- **랭킹**: 상위 3명 시상대(🥇🥈🥉, 1등은 통통 튐), **내 순위 카드**(이름으로 내 줄을 찾는다), 내 줄 강조와 "나" 표시, 순위 메달, 그라데이션 막대(100%는 초록~금색).
- **최근 7일 학습 기록**: 요일별 동그라미(끝낸 날은 금색 불꽃 + 그날 완료 세트 수, 오늘은 파란 테두리). 홈 상단 패널과 진행현황에 보인다 (세트 완료 기록에서만 계산).
- **사이드바·상단바**: 메뉴마다 색(홈 하늘, 진행현황 초록, 랭킹 금색, 관리자 보라), 활성 메뉴는 색 막대와 그라데이션 배경, 로고 "E" 배지, 사용자 아바타(이름 첫 글자).
- **세트 카드**: 분야 색 상단 띠(완료한 세트는 초록~금색), 호버 그림자. **모든 주요 화면**에 부드러운 등장 애니메이션(`fx-page`), 진행현황 로딩은 뼈대(skeleton).
- **XP·레벨·배지**: 세트를 끝낼 때 XP(처음 끝내면 문제당 10, 퍼펙트 보너스, 다시 끝낼 때마다 5로 복습 격려)가 쌓여 "Lv.3 실습생"처럼 레벨이 오른다. 홈 상단 패널에 레벨 막대, 진행현황에 **배지 10개**(첫 걸음, 5·10·20세트, 3·7일 연속, 퍼펙트, 단원 정복, 분야 정복, 복습왕, 잠긴 배지는 흐리게). 모두 완료 기록에서 계산한다.
- **콤보**: 문제를 연속으로 한 번에 맞히면 문제 화면 위에 🔥 N콤보. 틀렸다가 맞히면 끊긴다.
- **장식**: 세트 카드 순차 등장, 홈 배경 빛, 개념 퀴즈 화면 배경 그라데이션, 로그인 배경 빛과 `$ etude start` 깜빡이는 커서.
- **명예의 전당**: [spec_report.md](spec_report.md).
- 색상 토큰 추가: `warning`, `accent`, `gold`, `rose`, `sky`.

## 구현 위치

`QuestPanel.tsx`(탭·칸 막대), `SetComplete.tsx`(축하), `SetSelect.tsx`(링·색), `LoadingScreen.tsx`, `Celebration.tsx`, `ProgressRing.tsx`, `SoundToggle.tsx`, `sound.ts`, `banner.ts`, `index.css`(애니메이션), `tailwind.config.js`(색).

## 문제 풀이 화면 카드 레이아웃·폭 조절·전체보기 (2026-10-30)

KodeKloud 를 참고했다. (퀴즈 세트는 터미널이 없어 기존 단일 패널 그대로다.)

- **카드형**: 화면 바깥에 12px 여백을 두고, 문제 패널과 터미널을 둥근 카드(`rounded-2xl`, 테두리) 두 장으로 띄운다. 각 카드 위에 얇은 조작 줄이 있다 (문제: "문제" + 전체보기, 터미널: 글꼴·연결 상태 + 전체보기).
- **폭 조절**: 두 카드 사이의 손잡이를 끌어 문제 패널 폭을 25~70% 안에서 바꾼다. 더블클릭·Home 으로 기본 40% 로 되돌리고, 방향키(←→)로 2% 씩 움직인다 (`role="separator"`). 고른 비율은 `localStorage('etude.split')` 에 기억하고 읽기·쓰기에 실패해도 기본값으로 동작한다. 터미널은 `ResizeObserver` 로 칸 수를 다시 맞추고 서버에 알리며, 끄는 동안에는 한 프레임에 한 번만 보낸다.
- **전체보기**: 각 카드의 버튼(또는 Esc 로 되돌림)으로 한쪽만 화면 가득 보인다. 여백과 둥근 모서리는 없어지고, 가려진 쪽은 **언마운트하지 않고 숨긴다** (터미널 연결, 타이머, 채점 결과가 유지된다). 새 세트에 들어가면 풀린다.
- 검증: 프론트 타입 검사·빌드 통과. `미검증`: 화면 모습, 끌기 동작과 터미널 크기 동기화, 전체보기 전환 후 터미널 표시 (사용자 확인 필요).

## 검증

- `검증됨`: 프론트 타입 검사와 빌드 통과. 린트의 기존 오류 2개(`App.tsx`·`Progress.tsx`)는 이번 변경 이전부터 있었다.
- `미검증`: 모든 화면의 실제 모습(브라우저에서 확인 필요): 탭 전환과 풀이 모달, 힌트·풀이 사용 기록이 완료 기록에 반영되는지, 로딩 화면과 팁, 터미널 로고(`xterm` 줄바꿈), 홈 링과 색, 세트·단원 완료 연출과 효과음.

## 후속 (이 묶음에 넣지 않음)

- 시험형 세트의 카운트다운 시간 제한과 건너뛰기(세트별 제한 시간)는 복습·진단 세트와 함께.
- 조건별 채점 결과(항목별 통과 표시)는 채점 구조 변경이 필요해 별도 묶음.
