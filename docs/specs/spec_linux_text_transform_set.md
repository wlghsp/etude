# 명세 — 리눅스 텍스트 변환 손에 익히기 세트 (tr · cut · sed · sort -k · paste · 도구 잇기)

> 상태: **구현 완료(로컬), 화면 확인 대기** (2026-11-12). 세트 344. 근거: 세트 49(텍스트 도구 입문)와 47 은 `cut`·`sort`·`uniq` 를 한두 문제씩 다루고, 세트 177(sed·awk 심화)·189/276(정렬과 열 다루기)·210/282(`tr -s` 등)는 대부분 **고르는 퀴즈**다. 한 개의 CSV 명단으로 "글자 바꾸기 → 칸 뽑기 → 치환 → 특정 줄 → 줄 삭제 → 파일 직접 수정 → 칸 기준 정렬 → 파일 붙이기 → 도구를 이어 새 파일 만들기" 를 쌓고 **만들어진 파일의 내용을 채점**하는 터미널 세트는 없다.

## 목표

구성원 명단(`members.csv`, 8줄, 쉼표 구분)을 변환해 새 파일을 만든다. 문제마다 새 개념을 하나씩 붙인다: `tr 글자 글자`, `cut -d -f`, `-d` 구분 문자 확인, `s///` 의 기본(첫 번째만)과 `g`, `sed -n 'Np'`, `sed '/패턴/d'`, `sed -i`, `sort -t -k5,5nr`, `paste -d`, `sed -i` 의 안전한 작업 순서(백업·비교·정리), 도구를 이어 헤더가 있는 새 CSV 만들기. 쉬운 것부터 12문제.

## 원칙

- 터미널 9 + 빈칸 1 + 객관식 1 + 순서 1.
- setup 은 `/tmp/lab` 을 지우고 `members.csv`(번호,이름,팀,도시,점수,상태 — 8줄, 2명 `retired`, 점수 100 포함해 글자 비교와 숫자 비교가 달라지게 함), `bonus.txt`(8줄), `work.csv`(명단 복사본)를 다시 쓴다. 몇 번 실행해도 같은 상태다.
- 채점은 **결과 파일의 내용**(md5, 줄 수)을 기대값과 비교한다. 기대값은 생성기가 같은 데이터에서 따로 계산한다. 명령 문자열은 보지 않는다. 원본 `members.csv` 를 건드리지 않았는지도 함께 본다(1·5·7·8·12번).
- 모든 터미널 문제는 setup 직후에는 채점이 실패한다(대상 파일이 없거나 원본 그대로).
- 이미지(`etude-linux`)는 GNU sed 4.8, GNU coreutils 8.32(`tr`, `cut`, `sort`, `paste`), `diff`, `md5sum` 이 있다. `sed -i` 는 GNU 형식(`-i` 뒤 접미사 없음)을 쓴다. 채점은 `sh -c`, 풀이는 `bash`. 네트워크·`sleep` 없음.
- 객관식 정답은 보기 첫 번째로 적고 도우미가 섞는다. 보기 길이를 비슷하게 맞췄고 해설은 보기와 모순되지 않는다. 빈칸 칩(`,` `;` `:` `|`)은 명단이 쉼표로 나뉘므로 정답이 하나뿐이다.
- 순서 문제는 순서가 하나로 정해지는 작업(백업 → 수정 → 비교 → 정리)으로 골랐다.
- 이름·도시·팀은 가상 값(romanized 이름, `dev/ops/qa`)이고 IP·도메인·회사·내부 시스템 이름을 쓰지 않는다. 힌트는 "어떻게 살펴보나" 만 말한다.
- 문서 링크: man7.org 의 `tr`·`cut`·`sed`(POSIX 명세)·`sort`·`paste` (모두 200 확인).
- 겹침 점검: 세트 177·189·276·210 은 퀴즈 위주이고 터미널 문제는 47(cut 1개, sort 1개)·49(`sort | uniq`, cut)뿐이다. 세트 341 은 접속 로그 분석(awk·uniq -c)이라 이 세트와 주제가 다르다. 이 세트의 차별점은 `sed`(치환·`-n`·`d`·`-i`)와 `paste`, 그리고 변환 결과 파일 채점이다.

## 세트 구성 (12개, 세트 344)

| # | 형식 | 제목 | 새로 익히는 것 | 채점 |
|---|------|------|----------------|------|
| 1 | 터미널 | 글자를 다른 글자로 바꾸기 (tr) | `tr ',' ' ' < 파일` | `members_space.txt` 내용 일치, 원본 유지 |
| 2 | 터미널 | 쉼표로 나뉜 칸 하나 뽑기 (cut -d -f) | `cut -d, -f2` | `names.txt` 내용 일치, 8줄 |
| 3 | 빈칸 | 구분 문자 지정하기 (cut -d) | 파일의 구분 문자 확인 | 칸 1개 (`,`) |
| 4 | 객관식 | sed s/// 는 한 줄에서 몇 번 바꿀까? | `s///` 기본은 처음 하나만 | 정답: `eng,dev,dev` |
| 5 | 터미널 | 줄 안의 것을 전부 바꾸기 (sed s///g) | `g` 플래그 | `members_table.txt` 내용 일치, 원본 유지 |
| 6 | 터미널 | 특정 줄만 출력하기 (sed -n 'Np') | `-n` 과 `4p` | `fourth.txt` 4번째 줄만, 1줄 |
| 7 | 터미널 | 패턴이 있는 줄 지우기 (sed '/패턴/d') | `/패턴/d` | `active.csv` 내용 일치, 원본 유지 |
| 8 | 터미널 | 파일을 직접 고치기 (sed -i) | `-i` 제자리 수정 | `work.csv` 내용 일치, 원본 유지 |
| 9 | 터미널 | 열을 기준으로 정렬하기 (sort -t -k) | `-t` `-k5,5` `n` `r` | `by_score.csv` 내용 일치(100 이 맨 앞), 8줄 |
| 10 | 터미널 | 두 파일을 옆으로 붙이기 (paste) | `paste -d,` | `members_bonus.csv` 내용 일치, 8줄 |
| 11 | 순서 | 실수 없이 파일을 고치는 순서 | 백업 → `sed -i` → `diff` → 정리 | 4조각 |
| 12 | 터미널 | 도구를 이어서 새 CSV 만들기 (sed \| cut \| sort) | 헤더 + 파이프라인 + `>>`, cut 뒤 칸 번호 | `summary.csv` 내용 일치, 7줄, 원본 유지 |

- 빈칸·순서·객관식은 터미널이 필요 없어 터미널 창이 보이지 않는다.
