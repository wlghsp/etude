# 명세 — 리포트(명예의 전당)

> 상태: **구현 완료(로컬), 화면 확인 대기** (2026-10-30)

## 목적

누가 열심히 하는지 이름을 불러 칭찬하는 화면이다. 이름이 불리는 것 자체가 동기가 된다. 랭킹(완료한 세트 수)과 달리 **연속 학습, 이번 주 열공, 정답률** 같은 다른 면을 칭찬한다.

## 상

| 상 | 기준 |
|---|---|
| 🔥 연속 학습왕 | 오늘(없으면 어제)부터 이어진 연속 학습일이 긴 순서 (세트 완료가 있는 날 기준) |
| 💪 이번 주 열공상 | 최근 7일 세트 완료 횟수 |
| 🎯 정답률 왕 | 문제·세션마다 **첫 시도가 통과**한 비율. 시도가 10개 이상인 사람만 |
| 💯 퍼펙트 달인 | 힌트·풀이 없이 끝낸 세트 완료 횟수 |
| 🔁 복습왕 | 같은 세트를 다시 끝낸 횟수 합계 (반복 학습 격려) |

- 각 상은 상위 3명까지, **값이 0보다 큰 사람만** 높은 순서로 보인다. 낮은 사람은 드러내지 않는다 (위축 방지).
- 대상은 랭킹과 같이 회원(`role = 'member'`)이다.
- **이번 주 MVP**: 최근 7일 완료가 가장 많은 사람, 같으면 연속 학습일, 그다음 이름 순.
- 시간은 순위에 쓰지 않는다 (기존 결정). 정답률은 채점 기록에서 계산해 화면에는 비율만 보인다.

## 구현

- 서버: `services/report.ts`(`buildReport` 순수 계산 + `getReport` 조회), `GET /report`(로그인 필요).
- 화면: 사이드바의 독립 메뉴 **명예의 전당**(랭킹 아래, `pages/Hall.tsx`, 열 때 불러온다. 2026-10-30 랭킹 탭에서 분리). MVP 배너, 상 카드, 내 이름은 "나"로 강조, 수상자가 없으면 "첫 번째 주인공이 되어 보세요!".

## 검증

- `검증됨`: `report.test.ts`(연속일 계산 경계, 상위 3명, 시도 10개 미만 제외, 값 0 제외, MVP 동점 처리, 조회 구성) 포함 백엔드 전체 211개 통과, 조회 SQL 6개를 로컬 DB 에서 실행, 프론트 타입 검사와 빌드.
- `미검증`: 화면 모습, 실제 데이터가 있을 때의 순위(로컬에는 완료 기록이 거의 없다), 시간대 경계(날짜는 DB 기준이다).

## 소박한 상 (작은 상)

큰 상 아래 "소박한 상 🎈" 작은 카드 그리드. 수상자가 있는 상만 보이고, 한 상에 3명까지(동점은 같이). 같은 규칙: 값이 있는 사람만, 회원만.

| 상 | 기준 |
|---|---|
| 🌱 꾸준상 | 최근 7일 중 세트를 끝낸 날 수 |
| 🌅 새벽형 / 🦉 올빼미 | 5~8시 / 22~4시에 끝낸 횟수 (DB 시각 기준) |
| 🏖️ 주말 열공 | 토·일에 끝낸 횟수 |
| 🧗 끈기상 | 문제·세션마다 3번 이상 틀리고도 결국 통과한 건수 |
| 🐧☸️🐳 분야 박사 | 분야(리눅스·k8s·도커)별 끝낸 서로 다른 세트 수 |
| 📣 응원상 | 쓴 댓글(삭제 제외) + 누른 좋아요 수 |
| 🌿 성장상 | 최근 7일 완료 − 그 전 7일 완료가 양수인 사람 |

- `검증됨`: `report.test.ts` 15개 통과, 백엔드 전체 244개 통과, 프론트 타입 검사, 새 SQL 5개를 로컬 DB 에서 오류 없이 실행(로컬엔 기록이 없어 결과 행은 비어 있음).
- `미검증`: 화면 모습, 실제 기록이 있을 때의 순위.

## 이번 주 XP 순위 (2026-10-30)

랭킹 화면의 **이번 주 XP** 탭. 누적 세트 수 순위와 달리 최근 7일의 노력만 비교해서, 늦게 시작한 사람도 이번 주에는 앞설 수 있다.

- 기준: 최근 7일(오늘 포함)에 끝낸 세트들이 **그 시점에 늘린 XP**의 합. XP 규칙(처음 끝내면 문제당 10, 퍼펙트 보너스 문제당 5, 복습 5 XP 최대 5번)은 서버 `services/xp.ts` 한 곳이 기준이다.
- `GET /leaderboard/weekly` → `{ entries: [{ userId, userName, xp }], me: { xp, rank } }`. 회원만, XP 가 0보다 큰 사람만, 높은 순 상위 10명. `me.rank` 는 내가 상위 10명 안일 때만 값이 있다 (밖이면 null, XP 만 보여 준다). 낮은 순위 사람은 드러내지 않는다.
- 화면: 랭킹 화면 위의 `누적 세트 | 이번 주 XP` 전환. 상위 3명은 메달, 내 줄은 강조, 이번 주 기록이 없으면 "이번 주 첫 주인공이 되어 보세요!".
