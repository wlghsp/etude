# 명세 — 명예의 전당과 이번 주 XP 순위

> 상태: **구현 완료(로컬), 화면 확인 대기** (2026-10-30)

## 목적

누가 열심히 하는지 이름을 불러 칭찬하는 곳이다. 이름이 불리는 것 자체가 동기가 된다. 랭킹(누적 세트 수)과 달리 **꾸준함, 이번 주 열공, 정확함, 복습, 응원** 같은 여러 면을 칭찬한다. 칭찬하는 화면이므로 낮은 사람은 드러내지 않는다.

## 한눈에 보기 (분류)

| 분류 | 어디서 | 내용 | 기준 데이터 |
|---|---|---|---|
| **이번 주 MVP** | 명예의 전당 맨 위 배너, 소식 맨 위 배너 | 한 명 | 최근 7일 완료 수 |
| **큰 상** (5개) | 명예의 전당 | 상마다 상위 3명 | 완료 기록·채점 기록 |
| **소박한 상** (8종, 분야 박사는 분야별 1개씩) | 명예의 전당, "소박한 상 🎈" 카드 | 상마다 3명(동점은 같이) | 완료 기록·피드 기록 |
| **이번 주 XP 순위** | 랭킹 화면(누적 세트 순위 옆) | 상위 10명 + 내 XP | 최근 7일에 늘린 XP |

### 공통 규칙

- 대상은 회원(`role = 'member'`)이다.
- 값이 **0보다 큰 사람만** 높은 순서로 보인다. 수상자가 없는 소박한 상은 카드를 내지 않고, 큰 상은 "첫 번째 주인공이 되어 보세요!"를 보인다.
- 시간(빠르기)은 순위에 쓰지 않는다. 내 이름은 "나"로 강조한다.
- 날짜·시각은 DB 기준(`CURDATE()`, `NOW()`)이다.

## 큰 상 (상위 3명)

| 상 | 기준 |
|---|---|
| 🔥 연속 학습왕 | 오늘(없으면 어제)부터 이어진 연속 학습일이 긴 순서 |
| 💪 이번 주 열공상 | 최근 7일 세트 완료 횟수 |
| 🎯 정답률 왕 | 문제·세션마다 **첫 시도가 통과**한 비율. 시도가 10개 이상인 사람만 |
| 💯 퍼펙트 달인 | 힌트·풀이 없이 끝낸 세트 완료 횟수 |
| 🔁 복습왕 | 같은 세트를 다시 끝낸 횟수 합계 (반복 학습 격려) |

**이번 주 MVP**: 최근 7일 완료가 가장 많은 사람, 같으면 연속 학습일, 그다음 이름 순.

## 소박한 상 (작은 상, 상마다 3명·동점은 같이)

| 구분 | 상 | 기준 |
|---|---|---|
| 꾸준함 | 🌱 꾸준상 | 최근 7일 중 세트를 끝낸 날 수 |
| 시간대 | 🌅 새벽형 / 🦉 올빼미 | 5~8시 / 22~4시에 끝낸 횟수 |
| 시간대 | 🏖️ 주말 열공 | 토·일에 끝낸 횟수 |
| 끈기 | 🧗 끈기상 | 문제·세션마다 3번 이상 틀리고도 결국 통과한 건수 |
| 분야 | 🐧☸️🐳 분야 박사 | 분야(리눅스·k8s·도커)별 끝낸 서로 다른 세트 수 (분야마다 하나) |
| 교류 | 📣 응원상 | 쓴 댓글(삭제 제외) + 누른 좋아요 수 |
| 성장 | 🌿 성장상 | 최근 7일 완료 − 그 전 7일 완료가 양수인 사람 |

> 끈기상은 문제 단위 정보를 쓰지만 화면에는 "수상자와 건수"만 나오고 틀린 내역은 노출하지 않는다.

## 이번 주 XP 순위

누적 세트 수 순위와 달리 최근 7일의 노력만 비교해서, 늦게 시작한 사람도 이번 주에는 앞설 수 있다.

- 기준: 최근 7일(오늘 포함)에 끝낸 세트들이 **그 시점에 늘린 XP**의 합. XP 규칙(처음 끝내면 문제당 10, 퍼펙트 보너스 문제당 5, 복습 5 XP 최대 5번)은 서버 `services/xp.ts` 한 곳이 기준이다.
- `GET /leaderboard/weekly` → `{ entries: [{ userId, userName, xp }], me: { xp, rank } }`. 상위 10명. `me.rank` 는 내가 상위 10명 안일 때만 값이 있고, 밖이면 null 이라 XP 만 보여 준다 (낮은 순위는 드러내지 않는다).
- 화면: 랭킹 화면 위의 `누적 세트 | 이번 주 XP` 탭. 상위 3명은 메달, 내 줄은 강조, 기록이 없으면 "이번 주 첫 주인공이 되어 보세요!".

## 구현 위치

- 서버: `services/report.ts`(`buildReport` 순수 계산 + `getReport` 조회, `GET /report`), `services/xp.ts`(`getWeeklyLeaderboard`, `GET /leaderboard/weekly`), 연속일 계산은 `services/streak.ts`.
- 화면: 사이드바 **명예의 전당**(`pages/Hall.tsx`)과 랭킹(`pages/Leaderboard.tsx`)의 주간 XP 탭. 소식 화면의 MVP 배너는 `/report` 의 `mvp` 를 그대로 쓴다.
