## 알려진 한계

- 문서 본문에 대화형 명령(`n`, `d`, `p`, `w` 등)의 목록이 없어 퀴즈로 만들지 않았다. `o`·`g`·`I` 는 문서가 언급한 범위만 다뤘다.
- `-b`·`-c`·`-C`·`-H`·`-S`·`-u`·`-L`·`--lock` 의 세부, 종료 코드, 색상 설정은 뺐다.
- `-W`(새 파티션의 시그니처 삭제)는 `-w` 와 같은 구조라 해설에서만 언급했다.
- 컨테이너에서는 디스크를 나눌 수 없어 퀴즈로만 다룬다. 순서 문제 두 개는 일반 절차이다. 화면 확인은 하지 않았다(미검증).
