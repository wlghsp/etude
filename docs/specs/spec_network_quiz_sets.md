# 명세 — 네트워크 퀴즈 세트 378·379

> 상태: **구현 완료(로컬), 화면 확인 대기** (2026-11-13). 분야 분할 후 비어 있던 네트워크 분야의 개념 세트. 형식·근거 규칙은 [spec_storage_quiz_sets.md](spec_storage_quiz_sets.md)와 같다.

## 구성

새 단원 47 `네트워크 기초`(display_order 5)를 만들어 기존 단원 43 `연결이 안 될 때`(10) 앞에 둔다. 개념을 먼저 익히고 장애 상황집(117)으로 간다.

| 세트 | 제목 | 내용 |
|---|---|---|
| 378 | 네트워크 연결 요소: VLAN·브리지·본딩·MTU | VLAN·4,094개·트렁크, 리눅스 브리지, 본딩 기본 모드·active-backup·802.3ad·miimon, MTU 1500, `ip link` 명령 |
| 379 | 네트워크 주소와 경로: 사설 주소·CIDR·게이트웨이·라우팅·ARP | RFC 1918 사설 대역, /24·/26 호스트 수, 기본 게이트웨이·default 경로, 가장 길게 일치, metric, `ip route get`, ARP, `ss -tln` |

각 세트 12문제(객관식 9, 빈칸 2, 순서 1). 실습형이 아닌 이유: 샌드박스에 네트워크 권한이 없어 VLAN·본딩·브리지를 실제로 만들 수 없다.

## 근거 문서 (문제마다 `docs` 링크)

커널 본딩 문서, ip-link(8), ip-route(8), ip-neighbour(8), ss(8), bridge(8), RFC 1918, RFC 4632, 위키백과(802.1Q, MTU). 원문 확인: 본딩 기본 mode=balance-rr·active-backup·802.3ad 설명·miimon 기본 100, VID 12비트·4,094개, MTU 1500, 사설 대역 세 개, `ip route` metric 낮을수록 우선·`route get`, 이웃 테이블=ARP 테이블, ss 옵션, 최장 일치 전달.
