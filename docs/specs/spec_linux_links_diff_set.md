# 명세 — 링크와 파일 비교 손연습 세트 (ln · readlink · stat · diff · patch · cmp)

> 상태: **구현 중(로컬)** (2026-11-13). 세트 370, 리눅스 분야 `도구 다루기` 단원(id 2) 끝, 아이콘 🔗, 샌드박스 `linux`. 근거: 리눅스 실습에 비어 있던 "링크와 파일 비교" 주제. (처음 제안한 텍스트 처리는 세트 15·34·48·49·341·344 와 겹쳐 바꿨다.)

## 목표

`/tmp/lab` 에서 "심볼릭 링크 → readlink → 하드 링크 → 링크 개수 → 원본 삭제 후 차이 → diff → diff -u 패치 → patch 적용 → cmp -s" 를 쌓는다.

## 원칙

- 터미널 9 + 객관식 1 + 빈칸 1 + 순서 1. 문제마다 setup 이 `/tmp/lab` 을 새로 만든다.
- **배경은 문제 안에 적는다** (1번에 링크 개념과 연습 폴더 구조, 3·6·7번에 하드 링크·diff·패치 개념).
- 채점은 링크 상태(`-L`, `readlink`, inode `stat -c %i`, 링크 수 `%h`)와 파일 내용(`cmp`)을 직접 본다. 4·5번은 값이 하나뿐인 결과를 파일에 저장하게 한다.
- 한계: 같은 상태를 만드는 다른 명령도 통과한다. 9번은 `echo` 로 결과만 써도 통과한다(힌트·해설로 `cmp -s` 를 안내).
- 문서 링크: man7.org(symlink·inode), manpages.debian.org(ln·diff·patch·cmp) 200 확인. (gnu.org 는 접속 안 됨)
