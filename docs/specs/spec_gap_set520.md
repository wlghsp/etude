# 명세 — 세트 520 Docker 문제 해결 상황집: 볼륨·권한·디스크

> 상태: 작성 (2026-11-19). 근거: `docs/research/content_gap_2026-11-19/gap_docker.md` 필수 행(문제 해결 상황집: 볼륨·권한·디스크). 샌드박스 `docker`(dind), 카테고리 `도커`, 단원 26, display_order 741. 선행: 97(종료 코드·포트·디스크 첫걸음), 228(볼륨·바인드 마운트·`:ro`). 생성: `scripts/content-gen/new_sets/set520.py`.

## 설계

상황집 형식: 문제마다 setup 이 증상을 재현해 두고, 학습자는 오류 메시지·상태를 읽고 → 원인을 찾아 → 고친다. 이미지는 `alpine` 하나와 setup 이 빌드하는 작은 이미지만 쓴다. 97·228 과 겹치지 않게 `:ro` 볼륨 쓰기 거부(228 5번)와 디스크 "첫 단계"(97 5번)는 다시 묻지 않고, `--read-only` 루트 파일시스템·`system df -v`·`system prune` 범위로 확장한다.

## 메모

- `sh -c 'echo ... > /tmp/state; sleep 3600'` 처럼 `;` 로 이으면 리다이렉션 실패 후에도 `sleep` 이 실행돼 컨테이너가 종료되지 않는다. 3번 문제는 `&&` 로 이어 실패 시 종료되게 했다.
- 5·6번 등은 이미지 빌드·볼륨 용량(최대 30MB)을 쓴다. 로컬에서 Docker Hub 429 로 `alpine` 을 받지 못하면 검증이 가짜로 실패한다.
