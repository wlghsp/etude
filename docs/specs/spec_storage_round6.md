## 수용 조건

1. 마이그레이션 재실행 시 0개 적용. 2. `check-content.sh`·`check-migrations.sh` 통과. 3. 12문제, 분야 내 display_order·아이콘 중복 없음. 4. 정답 길이 경고 0.

## 알려진 한계

- lvcreate: `-L` 에 단위 접미사가 없을 때의 기본 단위는 문서가 분명히 적지 않아 문제로 만들지 않았다. RAID 패리티 배치·재구축 동작도 뺐다.
- mke2fs: mke2fs.conf 문법(`mke2fs.conf(5)`), -I·-E 계산 세부, 기본 inode·저널 크기는 문서에 없어 뺐다.
- fsck: -a·-y·-f 와 e2fsck 동작은 이 문서에 없어 뺐다. "마운트된 파일시스템을 점검하지 말 것"은 -M 설명뿐이라 일반 규칙으로 쓰지 않았다.
- 컨테이너에서 LVM·mkfs 실행은 권한이 없어 퀴즈로만 다룬다. 순서 문제 세 개는 문서 설명을 이은 일반 절차이다. 화면 확인은 하지 않았다(미검증).
