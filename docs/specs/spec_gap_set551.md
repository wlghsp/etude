# 명세 — 세트 551 볼륨 백업·복원과 권한: tar·헬퍼 컨테이너·uid

> 상태: 작성 (2026-11-20). 샌드박스 `docker`, 카테고리 `도커`, 단원 34, display_order 811. 선행: 볼륨(세트 228), 볼륨 상황집(세트 520). 생성: `scripts/content-gen/new_sets/set551.py`. 근거: `docs/research/content_gap_2026-11-19/gap_docker.md` 의 '볼륨 백업·복원과 권한' 행.

헬퍼 컨테이너(`alpine`)로 볼륨을 들여다보고 tar 로 백업·복원·이전하며, `--volumes-from`, `--user`, `cp -a` 로 파일 주인(uid)을 다룬다. 520 이 "Permission denied 를 고치기"를 다루므로 여기서는 **백업·복원 흐름과 만들어지는 파일의 주인**에 집중한다(520:2·8 의 chown 해결과 겹치지 않음). 이미지는 `alpine` 만 쓴다.

## 구성

| # | 형식 | 개념 | 확인 |
|---|---|---|---|
| 1 | 객관식 | 볼륨 백업은 헬퍼 컨테이너 + tar (`docker cp`·`save`·`commit` 은 아님) | |
| 2 | 실습 | 헬퍼로 `ls -lR` 해서 볼륨 내용 저장 | 파일 이름·하위 폴더 파일 |
| 3 | 실습 | `tar czf` 로 appdata 백업 | 백업 파일 + 내부 목록 |
| 4 | 실습 | `tar tzf` 로 풀지 않고 목록 확인 | 목록 파일, 백업 유지 |
| 5 | 빈칸 | 풀기 동작 `xzf` | |
| 6 | 실습 | 새 볼륨 `restored` 에 복원 | 내용·하위 폴더·uid 1000 |
| 7 | 실습 | `--volumes-from db` 로 실행 중 백업 | db 실행 유지, 목록에 table.dat |
| 8 | 실습 | `--user 1000:1000` 으로 백업 파일 주인 지정 | 파일 주인 uid 1000 |
| 9 | 실습 | `cp -a` 로 볼륨 → 볼륨 이전(소유자 보존) | 내용·uid 1000 |
| 10 | 객관식 | 쓰는 중인 DB 볼륨은 멈추거나 덤프 도구로 | |
| 11 | 실습 | root 전용 파일을 일반 uid 로 백업 → Permission denied → root 헬퍼로 | 오류 저장, 아카이브에 secret.txt, 권한 600 유지 |
| 12 | 순서 | 멈춤 → 백업 → 목록 확인 → 복원 → 확인 | |
