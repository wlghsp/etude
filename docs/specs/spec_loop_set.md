# 명세 — 리눅스 반복 작업 한 줄로 끝내기 (세트 35)

> 상태: **구현 완료(로컬), 화면 확인 대기** (2026-10-30)

## 배경과 목적

`for` 반복문은 세트 17 #6(스크립트 파일로 1~N 더하기)이 유일했다. 현장에서 자주 쓰는 형태(파일 여러 개 처리, 서버 목록 순회, 한 줄 반복)를 연습하는 곳이 없었다. 반복문은 서버 점검·일괄 정리의 기본이라 세트로 만든다.

## 전제 (앞에서 배운 것)

- 변수와 와일드카드(glob): 세트 21, 17
- 파이프·리다이렉션·`&&`·`||`: 세트 34 (이 세트의 선수 지식)
- 그래서 표시 순서는 세트 17 바로 뒤 (`display_order` 95)

## 구성 (10문제, 실습 8 + 객관식 2)

| # | 내용 | 종류 |
|---|---|---|
| 1 | `for x in a b c` 기본형 | 실습 |
| 2 | `*.log` 와일드카드로 파일 여러 개 처리 | 실습 |
| 3 | `seq` 와 `$( )` 로 숫자 범위 반복 | 실습 |
| 4 | `${f%.txt}` 로 확장자 일괄 변경 | 실습 |
| 5 | 서버 이름 목록 순회 (`getent hosts`) | 실습 |
| 6 | `while read` 로 파일을 한 줄씩 | 실습 |
| 7 | 반복 안에서 `[ -s ]` 와 `\|\|` 로 골라 삭제 | 실습 |
| 8 | `break` 로 조건을 만나면 멈추기 | 실습 |
| 9 | `for f in $(ls)` 가 공백 이름에서 깨지는 이유 (단어 분리) | 객관식 |
| 10 | 반복문 뒤에 파이프를 이어 결과 읽기 | 객관식 |
