# 점검 — 쉽고 친절한 문제 (2026-10-30)

> 기준: "듀오링고는 쉬워서 계속하게 된다. 어렵고 불친절하면 떠난다." 문제는 친절해야 하고, 학습자의 빈 구멍을 메워야 하며, 맞췄을 때 기분이 좋아야 한다.

## 점검 방법

DB 의 104개 세트·1128문제를 기준으로 기계적으로 센 값이다 (설명 길이, 첫 문제 형식, 연속 실습 수, 힌트·해설 유무).

## 결과

| 항목 | 결과 | 판단 |
|---|---|---|
| 힌트 | 모든 문제에 있음 | 양호 |
| 객관식·빈칸·순서 해설 | 모두 있음 | 양호 |
| 정답 효과음 | 있음 (`sound.ts`, 정답 올라가는 세 음), **기본값은 꺼짐** | 처음 쓰는 사람은 존재를 모름 |
| 세트 1~31 (옛 실습 세트) | 첫 문제가 짧고 쉬움(100~200자). 다만 처음부터 끝까지 터미널 실습만 이어짐 | 개념을 가볍게 먼저 보는 입문 세트(38~47)가 앞서므로 대체로 괜찮음 |

| 세트 33 (k8s 쉬운 장애 고치기) | 이름은 "쉬운"인데 첫 문제가 249자, 다음이 292자, 5번은 530자 | 이름과 난이도가 어긋남 |

## 손볼 순서 (제안)

1. ~~무거운 문제 짧게~~ → **하지 않는다.** 27문제를 하나씩 읽어 보니 이미 "상황 → 할 일 → 완료 조건" 구조이고, 긴 부분은 개념 설명이라 필요한 내용이다. 어려운 문제는 정당하게 존재해도 되고 억지로 쉽게 만들지 않는다 (사용자 방향, 2026-10-31). 대신 화면에서 "완료 조건"을 박스로 눈에 띄게 하는 것을 검토한다.
2. **쉬운 첫걸음:** 세트 32~37 앞에서 한 번에 한 개념만 확인하는 가벼운 문제(빈칸·객관식)를 먼저 둔다. (기존 문제의 순서는 바꾸지 않고 새 입문 세트로 분리)
3. **효과음 기본값:** 처음 방문 때 "정답 효과음을 켤까요?" 한 번 안내한다 (사무실 환경 때문에 기본 꺼짐은 유지).
4. **새 세트 규칙:** 첫 3문제는 바로 맞출 수 있게, 한 문제에 새 개념 하나, 설명 250자 이내.

## 진행 상황

- 입문 세트 4개 추가(쉬운 빈칸·순서·객관식 10문제씩, 따뜻한 해설): 105 반복 입문(→35), 106 이름 통신 입문(→36), 107 k8s 장애 읽기 입문(→33), 108 k8s 통신 입문(→37). 각 세트는 대상 세트 바로 앞에 배치.

- 남음: 완료 조건 박스 강조, 세트 32 입문 여부 검토.
