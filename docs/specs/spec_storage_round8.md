## 알려진 한계

- fstab: 파일시스템별 마운트 옵션 세부는 mount(8)·각 파일시스템 문서 영역이라 뺐다. systemd 와의 차이는 문서가 systemd 문서를 가리켜 뺐다.
- findmnt: 열 목록(--help), --filter 식 문법, --poll 의 부가 열, 종료 코드는 뺐다.
- umount: 비특권 사용자 제약과 루프 장치 자동 해제 세부는 뺐다. 종료 코드는 0·1·2 만 다뤘다.
- 컨테이너에서는 블록 장치를 마운트할 수 없어 퀴즈로만 다룬다. 순서 문제 세 개는 일반 절차이다. 화면 확인은 하지 않았다(미검증).
