> 상태: **구현 중(로컬)** (2026-11-13). 세트 372, 데이터베이스 분야 `SQL 기초` 단원(id 30) 끝(세트 371 뒤), 아이콘 🔀, 샌드박스 `linux-db`. 근거: 366(조회 기초)에 이은 심화. 사용자가 콘텐츠 세트를 알아서 이어 가라고 위임했다(2026-11-13).

## 목표

`shop`(고객·상품·주문)에서 "LEFT JOIN 짝 없는 행 → 세 테이블 JOIN → HAVING → 평균 서브쿼리 → IN 서브쿼리 → CASE → 계산한 합 순위 → VIEW → COUNT DISTINCT" 를 쌓는다.

## 원칙

- 터미널 9 + 객관식 1 + 빈칸 1 + 순서 1. setup 은 세트 366 과 같은 `shop` 데이터.
- 배경은 문제 안에 적는다(1번에 테이블 구조와 JOIN 개념, 8번에 VIEW 개념).
- 채점은 366 과 같이 저장한 출력 파일을 같은 쿼리의 실제 결과와 비교한다(순서 무관은 sort, 7번은 순서까지). 8번(VIEW)은 컬럼 순서·행 수·값을 조회한다.
- 한계: 같은 결과를 내는 다른 쿼리도 통과한다. 4번에서 평균을 직접 적어도 결과가 같아 통과한다(힌트·해설로 안내).
