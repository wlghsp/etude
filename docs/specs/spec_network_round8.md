## 알려진 한계

- conntrack(8)은 가져온 문서가 -L·-D·-E 위주여서 세트로 만들지 않았다(대신 ip-link·ip-netns). curl 은 문서 발췌가 중간에서 끊겨 보류했다.
- ip-link: 확보한 문서는 2012년판 렌더링이라 최신 type 목록과 다를 수 있다. wireguard 는 목록에 없어 다루지 않았다. `ip -s link` 통계는 문서에 없어 뺐다. 실습은 권한(NET_ADMIN) 때문에 퀴즈로만 다룬다.
- ip-netns: 새 네임스페이스의 loopback 기본 상태, attach·monitor 출력 형식, nsid 자동 할당 규칙은 문서에 없어 뺐다.
- 순서 문제 두 개는 문서 설명을 이은 일반 절차이다. 화면 확인은 하지 않았다(미검증).
