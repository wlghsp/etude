## 구성 (12문제, 세트 479, sandbox `linux`, 분야 리눅스)

터미널 9문제는 학습자가 `/tmp/lab/*.sh` 스크립트를 직접 만들고, 채점이 **스크립트를 실행해 출력·종료 코드를 확인**한다 (파일 존재만 보지 않는다).

| # | 형식 | 내용 | 채점 |
|---|---|---|---|
| 1 | 터미널 | `"$@"` 로 인자 한 줄씩 | 공백 든 인자 보존 |
| 2 | 터미널 | `while` + `shift` 합계 | 여러 입력, 인자 없을 때 0 |
| 3 | 터미널 | `getopts "n:v"` | 옵션 순서가 달라도 같은 출력 |
| 4 | 터미널 | `set -eu` | start 만 출력, 종료 코드 ≠ 0 |
| 5 | 터미널 | 배열·`+=`·`${#a[@]}` | 4, choi |
| 6 | 터미널 | 연관 배열 | kim=30, lee=25 |
| 7 | 터미널 | `read` + here-string | 30 |
| 8 | 터미널 | 함수와 `local` | 여러 입력의 최댓값 |
| 9 | 터미널 | `trap … EXIT` | work, cleanup, 종료 코드 3 |
| 10 | 객관식 | `"$@"` 와 `"$*"` | |
| 11 | 빈칸 | `set -{0}` (e) | |
| 12 | 순서 | 스크립트 뼈대 순서 | |

- 채점은 입력을 바꿔 여러 번 실행한다 (한 가지 출력에 맞춘 거짓 통과 방지). 근거: GNU Bash 매뉴얼.

## 알려진 한계

`set -o pipefail`, `select`, 프로세스 치환 `<( )`, 서브쉘과 변수 범위, `getopts` 의 긴 옵션(`--name`)은 다루지 않았다.
