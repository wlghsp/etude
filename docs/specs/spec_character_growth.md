# 명세 — 캐릭터 성장 ("전사 키우기")

> 상태: **초안** (2026-10-30). 재미 요소라 콘텐츠보다 우선순위는 낮다. 아래 "확인할 결정" 3가지를 정하면 구현한다.
> 계기: "전사, 여전사를 양성하는 것이 목표다. 캐릭터가 아기에서 계속 강한 전사로 성장하는 설정과 화면 표시."

## 원칙

1. **새 규칙을 만들지 않는다.** 성장 단계는 지금의 레벨(`levelInfo`, 10단계)에 1:1로 입힌다. 레벨·XP 규칙의 기준은 서버 `xp.ts`·`gamification.ts` 한 곳이고, 캐릭터는 그 값을 **보여 주기만** 한다 (서버 변경 없음).
2. **좋은 소식만, 응원 중심** (기존 확정 원칙). 낮은 단계를 다른 사람과 비교해 보여 주지 않는다. 다른 사람에게는 "전사로 진화했어요" 같은 좋은 소식만 소식 탭에 올린다.
3. **가볍게 시작한다.** 그림은 이모지와 SVG 조합으로 만들고, 캐릭터 정의를 **데이터 한 파일**로 분리해 나중에 일러스트로 바꿔도 화면 코드는 그대로 두게 한다.
4. 성별을 고르게 강요하지 않는다. 기본은 하나의 "에투드 전사"이고, 모양(색·머리 장식)만 고르게 하는 것은 이후 선택 사항이다.

## 성장 단계 (레벨 → 캐릭터)

| 레벨 | 칭호(기존) | 캐릭터 | 모습 (이모지 구성안) |
|---|---|---|---|
| 1 | 새싹 | 알 | 🥚 |
| 2 | 견습생 | 아기 전사 | 🐣 |
| 3 | 실습생 | 꼬마 전사 | 🐥 + 나무 막대 |
| 4 | 현장 요원 | 견습 전사 | 🪵🗡️ |
| 5 | 숙련자 | 전사 | ⚔️ |
| 6 | 베테랑 | 중갑 전사 | ⚔️🛡️ |
| 7 | 엘리트 | 정예 전사 | 🛡️⚔️✨ |
| 8 | 마스터 | 대장 | 👑⚔️ |
| 9 | 그랜드마스터 | 영웅 | 🦅⚔️ |
| 10 | 레전드 | 전설의 전사 | 🐉⚔️ |

- 위 이모지는 **자리표시**다. 실제 모양은 "확인할 결정 1"에 따라 정하고, 단계별 이름·설명은 `characters.ts` 한 곳에 둔다.
- 칭호(새싹…레전드)는 그대로 두고, 캐릭터 이름은 그 아래 보조 문구로 쓴다.

## 장비 (분야 정복)

- 분야 하나를 **정복**(그 분야의 공개 세트를 모두 끝냄)할 때마다 장비 하나가 붙는다. 이미 있는 배지 `분야 정복` 판정(`gamification.ts` 의 `categories`)을 재사용한다.
- 장비: 리눅스 🗡️ 검, 도커 🛡️ 방패, k8s ⛑️ 투구, Git 🧣 망토, 미들웨어 🎒 도구 가방, 인프라 🏗️ 망치 (분야가 늘면 `characters.ts` 에 한 줄 추가).
- 여러 분야를 고루 정복한 사람이 한눈에 보이는 것이 목적이다.

## 화면

| 위치 | 표시 |
|---|---|
| 내 진행현황 "내 상태" 카드 | 큰 캐릭터(단계 이름·설명), 장비, 다음 단계까지 남은 XP |
| 홈 상단 띠, 사이드바 | 작은 캐릭터(레벨 칩 옆). 지금의 레벨 칩을 대체하지 않고 덧붙인다 |
| 세트 완료 화면 | 레벨이 올랐을 때 **진화 연출** (새 모습 공개, 한 번만). 지금의 "레벨 업!" 문구 자리 |
| 소식 탭 | 진화하면 "OO님이 {캐릭터 이름}(으)로 성장했어요" 좋은 소식 한 줄 (기존 축하 카드 형식) |

- 연속 학습일은 캐릭터가 활기차 보이는 정도의 작은 표시(예: 불꽃 이모지)로만 쓰고, 끊겨도 벌을 주는 표현은 쓰지 않는다.

## 구현 조각 (명세 확정 뒤)

1. `frontend/src/characters.ts`: 단계·장비 정의 (데이터), `Character` 컴포넌트(레벨, 장비 목록 → 그림). 테스트: 레벨별로 올바른 단계가 나오는지.
2. 진행현황 카드와 홈 띠·사이드바에 표시.
3. 세트 완료 화면의 진화 연출. 진화 여부는 `xp.prevLevel`·`xp.level` 로 판단(이미 응답에 있음).
4. 소식 탭 문구: 서버의 축하(`cheers`) 계산에 "레벨이 올랐다"를 더할지 여부는 별도 결정 (서버 변경이 필요하다).

## 확인할 결정

1. **느낌**: 귀여운 마스코트(둥근 이모지, 홈의 마스코트와 어울림) vs 판타지 전사(갑옷·검). 추천: 귀여운 쪽.
2. **캐릭터 그림**: 이모지 합성으로 시작(추천) vs SVG 직접 제작.
3. **소식 탭 진화 알림**: 서버 변경(축하 규칙 추가) 포함 여부. 추천: 1차에서는 제외하고 화면 표시만.
