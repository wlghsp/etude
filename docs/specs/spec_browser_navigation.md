# 명세 — 브라우저 뒤로가기 처리

> 상태: **구현 완료(로컬 빌드), 브라우저 확인 대기** (2026-10-29).

## 문제

이 앱은 URL이 아니라 내부 상태(`page`, `selectedSetId`)로 화면을 바꾼다. 그래서 화면을 옮겨도 브라우저 기록에는 아무것도 쌓이지 않아, 문제 화면에서 뒤로가기를 누르면 **앱을 떠나 이전 사이트로** 가 버렸다.

## 동작

- 화면 이동(홈, 진행현황, 랭킹, 관리자, 세트 입장)을 `history.pushState` 로 기록에 남기고, `popstate` 에서 상태를 맞춘다. 라우터 라이브러리는 추가하지 않았다.
- **뒤로가기:** 앱 안의 이전 화면으로 돌아간다. 문제 화면에서는 홈으로 나간다 (환경은 기존 홈 이동과 같이 정리된다).
- **일부만 푼 세트에서 나갈 때** (완료 기록이 아직 없는 상태): "지금까지 푼 n/전체가 기록되지 않아요. 나갈까요?" 확인 모달(`ConfirmModal`: 계속 풀기 / 나가기)로 받는다. 뒤로가기가 일어나면 먼저 문제 화면 기록을 다시 쌓아 화면에 머물고, 모달에서 "나가기"를 고르면 뒤로가기를 한 번 더 건다. "계속 풀기"·Esc는 그대로 남는다. 새로고침·탭 닫기도 같은 경우 한 번 묻는다 (`beforeunload`).
- 아직 아무것도 안 풀었거나 세트를 끝까지 완료했으면 확인 없이 나간다.
- **문제 화면에서 로고나 "홈으로"** 로 나올 때는 새 기록을 쌓지 않고 문제 화면 기록을 되돌린다 (이후 뒤로가기가 한 번 더 헛돌지 않게).
- **앞으로가기로 문제 화면에 돌아오려는 경우:** 터미널 환경을 복원할 수 없으므로 홈으로 보낸다.
- URL 주소는 바꾸지 않는다 (새로고침하면 지금처럼 홈으로 돌아간다).

## 확인 시나리오 (`미검증`, 브라우저)

1. 홈 → 세트 입장 → 뒤로가기: 홈으로 (사이트를 떠나지 않음)
2. 세트에서 문제 몇 개 풀고 → 뒤로가기: 확인 모달. 계속 풀기·Esc면 그대로, 나가기면 홈으로
3. 홈 → 진행현황 → 랭킹 → 뒤로가기 두 번: 진행현황 → 홈
4. 세트에서 로고 클릭으로 홈에 간 뒤 뒤로가기: 한 번에 앱 밖으로 나가지 않는지, 문제 화면이 다시 열리지 않는지
5. 세트를 끝까지 완료한 뒤 뒤로가기: 확인 없이 홈으로
