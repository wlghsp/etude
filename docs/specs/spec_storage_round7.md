## 알려진 한계

- tune2fs: 마운트 상태에서 수정하는 일반 경고는 문서에 없어(-j·-E clear_mmp 에만 언급) 문제로 만들지 않았다. 기능별 의미(ext4(5)), stride·stripe_width 등 확장 옵션 세부, 종료 코드는 뺐다.
- blkid: -w 옵션과 종료 코드 1 은 문서에 없어 뺐다. 캐시 설정 파일(blkid.conf)의 세부도 뺐다.
- 컨테이너에서는 블록 장치가 없어 퀴즈로만 다룬다. 순서 문제 두 개는 일반 절차이다. 화면 확인은 하지 않았다(미검증).
