## 수용 조건

1. 마이그레이션 재실행 시 0개 적용. 2. `check-content.sh`·`check-migrations.sh` 통과. 3. 12문제, 분야 내 display_order·아이콘 중복 없음. 4. 정답 길이 경고 0.

## 알려진 한계

- 문서 발췌(앞 10만 자)만 확인했다. Grow 모드 후반(SIZE CHANGES 이후), EXAMPLES, mdadm.conf 문법, `/proc/mdstat` 형식, `--detail` 출력 필드는 다루지 않았다.
- raid4·5·6·10 의 패리티 배치와 장애 허용 수는 문서 발췌가 한 줄 요약뿐이라 문제로 만들지 않았다.
- LVM lvcreate(8)는 기존 세트 410 과 겹쳐 이번에 쓰지 않았다(확인한 사실: -L/-l, %FREE, --type, -i/-I, -m, -Z 기본 y 등은 후속 세트 후보).
- 컨테이너(샌드박스)에서 md 장치를 만들 수 없어 퀴즈로만 다룬다. 순서 문제 두 개는 일반 절차이다. 화면 확인은 하지 않았다(미검증).
