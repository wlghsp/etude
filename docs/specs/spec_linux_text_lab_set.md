# 명세 — 텍스트 도구 손연습 세트 (480)

> 상태: **구현 완료(로컬), 화면 확인 대기** (2026-11-18). 근거: [spec_lab_expansion.md](spec_lab_expansion.md) 단원 단위 목표(단원 `텍스트·파일 도구 심화`는 실습 0개였다). 짝 퀴즈: 185/275(grep 정규식 심화), 189/276(정렬과 열), 181/274(압축·검증·diff), 169/271(find·tee·tr·uniq).

## 구성 (12문제, 세트 480, sandbox `linux`, 분야 리눅스)

데이터는 setup 이 `/tmp/lab` 에 만든다(로그 6줄, 점수, 용량, 단어, 두 표, 해시 목록). 채점은 결과 파일의 **내용**을 확인한다.

| # | 형식 | 내용 |
|---|---|---|
| 1 | 터미널 | `grep -E 'A\|B'` (4줄) |
| 2 | 터미널 | `grep -o 'id=[0-9]*'` (맞은 부분만) |
| 3 | 터미널 | `grep -vc` (INFO 아닌 줄 수) |
| 4 | 터미널 | `grep -nw` (줄 번호, 단어 단위) |
| 5 | 터미널 | `sort -k2,2nr -k1,1` (두 기준) |
| 6 | 터미널 | `sort -h` (K·M·G 단위) |
| 7 | 터미널 | `sort \| uniq -c \| sort -rn` (빈도) |
| 8 | 터미널 | `join` |
| 9 | 터미널 | `sha256sum --quiet -c` (바뀐 파일) |
| 10 | 객관식 | 옵션 없는 `sort` 의 순서 (문자열 기준) |
| 11 | 빈칸 | `sort -{0}` (h) |
| 12 | 순서 | 가장 흔한 모듈 찾는 파이프라인 |

근거: GNU grep 매뉴얼, GNU coreutils 매뉴얼(sort·uniq·join·SHA-2).

## 알려진 한계

`grep -P`(PCRE)·역참조, `cut`·`paste`·`tr`, `diff -u`·`cmp`·`patch`, `split`, `md5sum` 은 다루지 않았다.
