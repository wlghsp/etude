# 명세 — SQL 조회 손연습 세트 (WHERE · ORDER BY · 집계 · GROUP BY/HAVING · JOIN)

> 상태: **구현 완료(로컬), 화면 확인 대기** (2026-11-12). 세트 366, 데이터베이스 분야 `SQL 기초` 단원(id 30) 끝, `display_order` 550, 아이콘 🔍, 샌드박스 `linux-db`. 근거: 사용자 질문("데이터베이스 쿼리 실습도 가능한 환경인가?")과 "진행". `linux-db` 실습은 109(백업·복원)·126(구경하기)뿐이고, 쿼리를 직접 쳐 보는 세트는 없었다. `SQL 기초` 단원의 퀴즈 세트들과 개념은 겹치지만 이 세트는 **직접 쳐서 결과를 확인**하는 실습이다.

## 목표

`shop` 데이터베이스(고객 6, 상품 5, 주문 10)에서 "거르기 → 정렬·개수 → 범위 → 집계 → 묶기 → 묶음 거르기 → JOIN → LEFT JOIN → 세 테이블 합계" 를 한 단계씩 쌓는다.

## 원칙

- 터미널 9 + 객관식 1 + 빈칸 1 + 순서 1.
- setup 은 MariaDB 서버를 띄우고(`mysqld_safe`) `shop` 을 지우고 다시 만든다 (세트 126 과 같은 방식). 몇 번 실행해도 같은 상태다.
- 학습자는 `mariadb shop -e '쿼리' > /tmp/qN.txt` 로 결과를 저장한다. 채점은 파일을 **같은 쿼리를 실제로 실행한 결과**와 비교한다(결과 순서가 중요하지 않은 문제는 정렬해서 비교, 2번 ORDER BY 는 순서까지). 컬럼 별칭이 필요한 문제(4·5·6·7·9번)는 문제에 별칭을 적어 준다.
- 한계: 결과가 같으면 다른 쿼리도 통과한다(예: 서브쿼리). 의도한 쿼리는 힌트와 해설로 안내한다. 결과를 파일에 저장하는 방식이라 값을 직접 `echo` 로 적어도 통과할 수 있다.
- 가상 데이터만 쓴다. 문서 링크: mariadb.com/kb 의 select·where·order-by·group-by·joins-introduction·left-join (200 확인).
