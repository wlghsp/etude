# 화면 확인 체크리스트 (2026-11-18)

마지막 전체 화면 확인 이후 시간이 많이 지나 `미검증`으로 쌓인 항목을 기능 단위로 모았다. 세트별 "화면: 1~12번이 풀린다" 항목은 수백 개라 **분야별 대표 세트**로 대신한다. 확인할 때는 일반 `member` 계정과 `admin` 계정을 둘 다 쓴다.

> 배포 전 항목(★)은 아직 서버에 없다. 로컬 또는 배포 후에 확인한다.

## 1. 공개 범위 ★ (가장 먼저)

- [ ] `member` 로 로그인하면 분야가 **리눅스·k8s 둘만** 보인다 (도커·Git·미들웨어·DB·OpenStack·네트워크·가상화·스토리지는 안 보임).
- [ ] 닫힌 분야의 세트 URL 을 직접 열면 접근이 막힌다 (예: 네트워크 세트 `/…/466`).
- [ ] 진행현황·소식 탭·리더보드에 닫힌 분야 세트나 활동이 나오지 않는다.
- [ ] `admin` 은 10개 분야가 모두 보인다.
- [ ] 관리자 화면: 분야 헤더의 공개/비공개 토글이 동작하고, 닫았다 열면 `member` 화면에 즉시 반영된다.
- [ ] 관리자 화면: 분야의 "접근 N명" 패널에서 사용자를 추가하면 그 사용자(`member`)에게만 닫힌 분야가 보인다.

## 2. 단원 나누기 ★

- [ ] 리눅스: 단원이 기초 → 명령어 한 줄씩 1·2 → 운영 도구 → 텍스트·파일 도구 심화 → 쉘 스크립트 → find·읽기 → 도구 다루기 → 반복·스크립트 실습 → 네트워크와 통신 → 운영과 장애 대응 → 운영 실습과 systemd → 권한·진단·커널 순으로 보인다.
- [ ] k8s: 기초 → kubectl 실습 기초 → 워크로드와 설정 → Pod 수명주기 → 자원·kubectl 도구 → 롤아웃·Pod 스펙 → 컨테이너 실행 → 스케줄링과 워크로드 실습 → 스토리지와 네트워크 → … 순서.
- [ ] Git(관리자 화면): 기초 → 브랜치와 병합 → 병합과 이력 다듬기 심화 → 원격과 협업 → 되돌리기 → 기록 살펴보기 → 설정·패치·내부 구조.
- [ ] 한 단원이 10세트 안팎이고, 같은 단원 세트가 흩어지지 않고 이어진다. 단원 번호("N단원")가 순서대로 붙는다.
- [ ] 세트 완료 표시·진행률이 분리 전과 같다 (이미 끝낸 세트가 완료로 남음).
- [ ] (관리자, 3차 분리 후) 도커·네트워크·스토리지·가상화도 단원이 10세트 안팎으로 나뉘어 보인다. 가상화 `용어 지도` 단원이 맨 끝으로 간다.

## 3. 풀이 화면 (대표 세트로)

대표 세트: 리눅스 퀴즈 1개 + 실습 1개, k8s 퀴즈 1개 + 실습 1개, Git 퀴즈 1개.

- [ ] 퀴즈: 객관식·빈칸 칩·순서 맞추기 3유형이 모두 풀리고 채점·해설·근거 링크가 보인다.
- [ ] 실습: 터미널이 열리고 채점되며, 힌트·풀이 사용 표시가 보인다 (k8s 실습은 k3d 기동 시간 포함).
- [ ] 문제 수가 10개를 넘는 세트에서 진행 막대가 10칸마다 나뉘고 "N단계 / M단계"가 보인다.
- [ ] 문제 타이머: 시간이 흐르고, 탭을 숨기면 멈추고, 다른 문제를 갔다 와도 이어진다. 통과 시 걸린 시간이 보인다.
- [ ] 이어 풀기: 일부만 풀고 나갔다 들어오면 푼 문제가 완료로 표시되고 못 푼 첫 문제에서 시작한다. 이미 완료한 세트는 처음부터 시작한다.
- [ ] 세트 완료 화면: 완료 기록 1건, XP, 다음 세트 안내가 맞다.

## 4. 홈·진행현황·소식

- [ ] 홈 인사 카드: 세트 이름이 길어도 한 줄로 줄고 레이아웃이 깨지지 않는다. 다음 세트 카드 동작이 이전과 같다.
- [ ] 진행현황: 단원별 진행 막대, 다시 풀기 추천(힌트·풀이 사용 40% 이상) 표시.
- [ ] 리더보드: 완료 세트 수 순위가 맞다.
- [ ] 소식(활동 피드) 탭: 완료 활동이 보이고 응원(cheer)이 동작한다.
- [ ] 배포 후: 진행 기록 이전(backfill) 결과가 기존 사용자 화면에 맞게 나온다.

## 5. 새 분야 (열기 전 점검, 관리자 계정)

- [ ] 네트워크·가상화·스토리지·OpenStack 분야가 홈에 단원별로 보이고 각 세트가 열린다 (퀴즈 전용).
- [ ] 도커·Git·미들웨어·데이터베이스 대표 세트가 열리고 풀린다.

## 6. 기타

- [ ] 피드백 보내기(첨부 포함)가 동작한다.
- [ ] 모바일 폭에서 홈·풀이 화면이 깨지지 않는다.
- [ ] 로그아웃 후 재로그인, 세션 만료 처리.
